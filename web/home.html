Welcome to SkyscraperSolver. This site primarily hosts a static puzzle-bank API for other applications.

Curious about the solver itself? Try the solver in your browser — paste visibility clues, optionally provide a starting grid, and see the first solution. Everything runs locally via WebAssembly; no installation needed.

The puzzle-bank files are intended for programs rather than people. You're welcome to browse the raw JSON, but it is not an interactive puzzle gallery. For a friendlier experience, start with the solver above.
