Welcome to SkyscraperSolver. Explore curated Skyscraper puzzles and their difficulty distributions, or use the static puzzle-bank API in your own application.

Curious about the solver itself? Try the solver in your browser — paste visibility clues, optionally provide a starting grid, and see the first solution. Everything runs locally via WebAssembly; no installation needed.

The curated page summarizes available curated puzzles; the v1 and curated v1 JSON endpoints are for programmatic use. Candidate datasets are not published.
