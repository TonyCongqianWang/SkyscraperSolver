The solver runs in the browser; no download or compilation necessary to try it.

To use it in your own page, load solver.js and keep solver.wasm beside it. Call solve_web(clues, grid, max_solutions) through Emscripten's ccall:

<script src="solver.js"></script>
<script>
createSkyscraperSolver().then(module => {
  const result = module.ccall(
    "solve_web", "string",
    ["string", "string", "number"],
    ["1 3 3 0 0 0 0 2 0 0 0 0 0 0 0 0", "", 2]
  );
  console.log(result);
});
</script>

Clues: 4 × N digits, separated by spaces, ordered top (→), bottom (→), left (↓), right (↓). Grid: optional N × N space-separated digits, row-major; zero means empty. Supported sizes: 4–9.

Response: count|nodes|size|first_solution (row-major digits), or ERR:message. Use 2 as the solution limit to check uniqueness. 0 counts all solutions, but the wrapper currently accepts limits 1–100.

The call is synchronous and can be expensive. For interactive pages, run it in a Web Worker, as worker.js does. The returned string must be read before the next call.
