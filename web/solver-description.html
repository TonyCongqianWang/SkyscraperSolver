The solver runs in the browser; no download or compilation is necessary to try it.

The demo defaults to the latest stable release (or the latest prerelease if no stable release exists) and offers newer prereleases when available. versions.json lists available builds; the top-level solver.js and solver.wasm intentionally duplicate the default build to provide stable URLs.

Using the solver

Load solver.js and keep solver.wasm beside it. Call solve_web(clues, grid, max_solutions) through Emscripten's ccall:

<script src="solver.js"></script>
<script>
createSkyscraperSolver().then(module => {
  const result = module.ccall(
    "solve_web", "string",
    ["string", "string", "number"],
    ["1 3 3 0 0 0 0 2 0 0 0 0 0 0 0 0", "", 2]
  );
  console.log(result);
});
</script>

Clues: 4 × N space-separated digits, ordered top (→), bottom (→), left (↓), right (↓). Grid: optional N × N space-separated digits, row-major; zero means empty. Supported sizes: 4–9.

Response: count|nodes|size|first_solution (row-major digits), or ERR:message. Use a solution limit of 2 to check uniqueness; the wrapper accepts limits 1–100.

The solver call is synchronous and can be expensive. For interactive pages, run it in a Web Worker, as worker.js does. Read the returned string before the next solver call.
