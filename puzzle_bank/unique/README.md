# Unique puzzle banks

`puzzle_bank/unique/v1/minimal/size_N.json` contains the newest generated,
uniqueness-checked minimal puzzles for sizes 4–9. Each group includes its
canonical solution and an array of locally irreducible clue/given puzzles.

Use `bash generate_unique_banks.sh` to regenerate the current minimal banks
and fill the curated bank. The public website exposes these files under
`/assets/puzzles/unique/v1/minimal/`. The previously generated bank versions
have been removed from the current repository tree without rewriting history.
